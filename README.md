# موقع الأستاذ عامر البهلول — مكانك للتميز نحو التكنولوجيا

موقع تعليمي ثنائي اللغة (العربية/الفرنسية) جاهز للنشر على GitHub Pages.

## محتويات النسخة الأولى
- صفحة رئيسية وهوية تعليمية.
- تبديل اللغة بين العربية والفرنسية.
- أقسام للدارات الكهربائية، الحركة والزمن والطول، المنطق الرقمي، والروبوتيك.
- محاكاة تفاعلية لدارة كهربائية بسيطة (فتح/غلق القاطعة).
- سؤال QCM مع تصحيح فوري وإعادة المحاولة.
- تصميم متجاوب مع الهاتف والحاسوب.

## النشر المجاني على GitHub Pages
1. سجّل الدخول إلى https://github.com/
2. أنشئ مستودعًا جديدًا (New repository)، مثلًا باسم `amer-bahloul-technology`.
3. اجعل المستودع **Public** ثم أنشئه.
4. ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js` إلى جذر المستودع.
5. افتح Settings ثم Pages.
6. في Build and deployment اختر `Deploy from a branch`.
7. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
8. انتظر قليلًا حتى يظهر رابط الموقع في صفحة Pages.

سيكون الرابط غالبًا:
`https://YOUR-USERNAME.github.io/amer-bahloul-technology/`

استبدل `YOUR-USERNAME` باسم حساب GitHub الخاص بك.

## التخصيص قبل النشر
- راجع كتابة الاسم والصفة في `index.html`.
- أضف بريدًا مهنيًا أو روابط التواصل إن رغبت.
- أضف محتوى الدروس الحقيقي تدريجيًا بدل النصوص التمهيدية.

## ملاحظات
- الاستضافة عبر GitHub Pages مجانية للمستودعات العامة.
- الموقع لا يجمع بيانات التلاميذ ولا يحتاج إلى تسجيل دخول.
- لا ترفع أسماء التلاميذ أو نتائجهم أو بياناتهم الشخصية إلى هذا الموقع.
